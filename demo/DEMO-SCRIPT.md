# KeepThis 시연 대본

데모 타겟: `demo/index.html` (RefLib) · `npm run demo` → `http://localhost:4173`

**Gemini 호출은 전체 2회.** 라이브로 하든 녹화하든 같은 순서다. 4막 중 1막과 4막은 호출이
0회라 할당량과 무관하게 안전하고, 2·3막만 호출을 쓴다.

---

## 데모의 핵심 주장 — 대사를 쓰기 전에 정할 것

이 시연은 **"AI가 요청하지 않은 걸 했다"**를 보여주는 게 아니다. 그건 diff만 봐도 보인다.

보여주는 건 이것이다:

> **요청한 것이 전부 요청대로 잘 들어갔고, CSS 오류도 없는데, 내가 지키기로 한 것이 깨졌다.**

그래서 2막의 프롬프트는 화면에 실제로 생기는 것 **전부**를 요청해야 한다 — 필터와 트렌딩
섹션 둘 다. 하나만 요청한 척하면 청중은 "나머지는 눈에 보이잖아요"라고 생각하고, 그 순간
제품의 존재 이유가 약해진다.

**실측 근거** (뷰포트 1000×900):

| | 기본 | `#changed` |
|---|---|---|
| 레퍼런스 그리드 시작 y | 306px | **816px** |
| 완전히 보이는 레퍼런스 카드 | **6장** | **0장** |

밀린 510px 중 **트렌딩 섹션이 438px, 필터 바가 72px**다. 카드 한 줄이 180px이므로
트렌딩을 빼면 필터만으로는 반 줄도 못 민다 — 카드가 여전히 6장 보여서 Guardrail이 위반되지
않는다. 트렌딩은 데모에 필요하고, 그래서 프롬프트에 포함되어야 한다.

## 촬영 컷 리스트 — 원본 3분 20초 → 2배속 1분 40초

발표 시간 제약이 있을 때 쓰는 압축본. **막 구성은 아래 1~4막 그대로**이고, 잘라내는 것은
대기 시간과 부차적인 확인 동작뿐이다.

**전제 두 가지**
- 2배속에서는 **말이 안 들린다.** 영상은 무음으로 두고 발표자가 그 위에 직접 설명하는 것을
  기준으로 짰다. 그래서 각 컷에 "이때 할 말"을 적어뒀다
- 그러려면 화면이 **말보다 조금 느려야** 한다. 핵심 화면에서는 어색할 만큼 멈춰 있어야
  2배속에서 읽힌다. 반대로 대기·타이핑·외부 도구 실행은 편집에서 전부 잘라낸다

| # | 화면 | 원본 | 이때 할 말 | 편집 |
|---|---|---|---|---|
| 1 | `localhost:4173` → `SET AS BASELINE` | 8초 | "지금 이 화면이 제가 만족하는 상태입니다. 기준으로 저장합니다." | 패널 여는 동작은 잘라낸다 |
| 2 | **후보 3개가 뜬 시트에서 정지** | 12초 | "**AI를 부르지 않았습니다.** 코드가 방금 이 화면에서 관찰한 사실입니다. 그래서 즉시 뜹니다." | 그대로 — 여기가 첫 차별점 |
| 3 | 3번 후보 체크 → 문장 클릭 → 다시 입력 → `Done` | 20초 | "코드는 '주요 콘텐츠'라고 했는데 제가 지키고 싶은 건 레퍼런스 카드입니다. **제 말로 고칩니다.**" | 타이핑 중간을 잘라 8초로 |
| 4 | 주소창 `#changed` → 화면 전체 | 10초 | "여기서 '필터랑 트렌딩 추천 섹션 추가해줘'라고 했습니다. **둘 다 잘 들어갔고 CSS 오류도 없습니다.**" | 스크롤하지 말 것 — 첫 화면만 |
| 5 | `CHECK CHANGES` → 진행 표시 | 20초 | "코드가 먼저 세고, 그 다음에 Gemini가 판단합니다." | **1초로 압축** |
| 6 | **이슈 카드 + 근거 줄에서 정지** | 15초 | "'카드 6장은 보인다'고 했는데 지금 몇 장인지 보세요. **이 숫자는 코드가 센 겁니다.**" | 그대로 — 가장 중요한 컷 |
| 7 | `Guardrails checked` 3줄이 보이게 스크롤 | 8초 | "전부 깨진 게 아닙니다. 두 개는 지켜졌습니다." | 스크롤 속도 일정하게 |
| 8 | `Fix` 클릭 → **프롬프트에서 정지** | 15초 | "지우지 말라고 하고, 얼마나 비워야 하는지 숫자로 말하고, **각 방법의 비용까지** 적혀 있습니다." | 그대로 — 두 번째 차별점 |
| 9 | `Copy` → Claude Code 붙여넣기 → 실행 | 40초 | "적용은 제가 쓰는 도구에서 합니다. **이 도구는 코드에 손대지 않습니다.**" | **3초로 압축** — 실행 대기는 전부 잘라낸다 |
| 10 | 브라우저 새로고침 → 카드가 돌아온 화면 | 8초 | "카드가 돌아왔고, **필터도 트렌딩도 그대로 있습니다.**" | 그대로 |
| 11 | `CHECK CHANGES` → 결과 | 20초 | "다시 확인합니다." | **1초로 압축** |
| 12 | **✓로 넘어간 화면에서 정지** | 12초 | "지켜졌습니다. 발견 → 지시문 → 적용 → 재확인이 닫혔습니다." | 그대로 — 마지막 컷 |
| 13 | (여유 있으면) `#loading` → `CHECK CHANGES` → 차단 화면 | 12초 | "화면이 덜 그려졌으면 **API를 부르기 전에 코드가 막습니다.**" | 3초 정지면 충분 |

**원본 합계 약 3분 20초 → 2배속 약 1분 40초.** 13번을 빼면 1분 34초.

### 자를 것 / 남길 것

| 자른다 | 남긴다 |
|---|---|
| Gemini 응답 대기 (2회, 각 10~30초) | 후보 3개가 뜬 순간 |
| Claude Code 실행 대기 (30~60초) | 이슈 카드의 근거 줄 |
| 타이핑 중간 구간 | Fix 프롬프트 본문 |
| 접근성 행 펼치기 | ✓로 넘어간 마지막 화면 |
| 툴팁 `?` | |
| `측정된 변화` 펼치기 | |
| `ALSO CHANGED` 짚기 | |

접근성·툴팁·측정된 변화는 **질문이 나왔을 때 라이브로** 보여주면 된다. 셋 다 Gemini 호출이
0회라 무대에서 눌러도 안전하다.

### 촬영 팁

- 마우스를 천천히 움직인다. 2배속에서 커서가 순간이동하면 뭘 눌렀는지 안 보인다
- 정지 컷에서는 **커서를 그 요소 위에 올려둔다.** 발표자가 말로 가리키는 대상과 화면이 맞는다
- 한 컷씩 끊어 찍고 편집에서 붙이는 편이 낫다. 통으로 찍으면 한 군데 틀릴 때 전부 다시 찍는다
- 5·9·11번은 어차피 잘라낼 구간이므로 **실패해도 그 컷만 다시** 찍으면 된다

## 0. 시작 전 준비 (반드시 확인)

| # | 항목 | 확인 방법 |
|---|---|---|
| 1 | `npm run demo` 실행 중 | `http://localhost:4173`이 열림 |
| 2 | 확장 프로그램 재빌드 후 Reload | `chrome://extensions` → KeepThis → 새로고침 |
| 3 | Gemini 키 저장됨 | Side Panel에 키 입력 폼이 안 뜸 |
| 4 | **저장된 Baseline 삭제** | 아래 "리셋 절차" |
| 5 | 브라우저 확대 125~150% | 400px 패널 글자가 프로젝터에서 읽힘 |
| 6 | 스크롤 맨 위 | Baseline과 Check의 스크롤이 다르면 측정값이 흔들림 |
| 7 | **창 크기 고정** | Baseline과 Check 사이에 창이나 패널 폭이 바뀌면 수치가 달라짐 |
| 8 | **데모 페이지 백업 존재** | `demo/index.original.html` — 3막에서 파일이 수정되므로 테이크마다 복원 |

### 테이크 사이 복원

`demo/`는 git에 추적되지 않으므로 `git checkout`으로 되돌릴 수 없다. 3막을 다시 찍을 때마다:

```bash
cp demo/index.original.html demo/index.html
```

그 다음 브라우저에서 `#changed` 새로고침.

### 리셋 절차

`NO BASELINE` 화면부터 녹화하려면 저장된 Baseline을 지운다. **API 키는 남는다.**

1. `chrome://extensions` → KeepThis 카드의 **"서비스 워커"** 링크 → DevTools Console
2. 붙여넣기:
   ```js
   chrome.storage.local.remove("baseline:http://localhost:4173")
   ```
3. Side Panel을 **닫았다가 다시 연다** (패널이 화면 상태를 캐싱하고 있다)

키가 안 지워지면 `chrome.storage.local.get(null).then(d => console.log(Object.keys(d)))`로
실제 키를 확인한다.

## 1막 · 기준 세우기 — 호출 0회 · 약 90초

> **라이브로 해도 안전한 구간.** 네트워크를 타지 않으므로 할당량·지연·편차가 전부 없다.
> 실제로 돌아가는 확장 프로그램이라는 것을 여기서 보여주고 시작한다.

**화면**: `http://localhost:4173` (기본 상태) — 제목 `Reference Library`,
`Save to collection` 버튼, `All references` 아래 레퍼런스 카드 8장.

| 순서 | 동작 | 대사 |
|---|---|---|
| 1 | 주소창 `localhost:4173` · 스크롤 맨 위 | "지금 이 화면이 제가 만족하고 있는 상태입니다." |
| 2 | 확장 아이콘 → Side Panel 열기 | |
| 3 | `SET AS BASELINE` | "이걸 기준으로 저장합니다." |
| 4 | **후보 3개가 즉시 뜨는 것을 잠깐 둔다** | "**AI를 부르지 않았습니다.** 코드가 방금 이 화면에서 관찰한 사실을 문장으로 만든 겁니다. 그래서 즉시 뜨고, 오프라인에서도 뜹니다." |

여기서 뜨는 후보:
```
[✓] 본문의 주요 액션에 스크롤 없이 닿을 수 있다 (지금: "Save to collection")
[✓] 본문의 주요 섹션이 페이지에 남아 있다 (지금: "Reference Library")
[ ] 첫 화면에 주요 콘텐츠가 7개 이상 보인다
```

| 순서 | 동작 | 대사 |
|---|---|---|
| 5 | 세 번째 후보를 **체크하고, 문장을 클릭해서 고친다**<br>→ `스크롤 없이 레퍼런스 카드가 6장 이상 보인다` | "코드는 '주요 콘텐츠 7개'라고 관찰했는데, 제가 지키고 싶은 건 레퍼런스 카드입니다. **제 말로 고칩니다.** 코드가 초안을 쓰고 확정은 사람이 합니다." |
| 6 | (선택) `GUARDRAILS` 옆 `?` 눌렀다 닫기 | |
| 7 | (선택) 접근성 행 펼치기 | "이 페이지는 접근성 위반이 없어서 조용합니다. 있으면 규칙별로 묶여 나옵니다." |
| 8 | `Done` | |

**끝난 상태**: Guardrail 3개 저장, `BASELINE READY`.

> 후보 2개는 그대로 두고 세 번째만 고쳐 쓴다. 직접 추가하는 Guardrail은 넣지 않는다 —
> 위반이 하나면 이슈 카드도 하나, Fix도 하나여서 3막이 한 번의 붙여넣기로 닫힌다.

> **왜 "레퍼런스 카드"라고 특정해야 하는가** — `주요 콘텐츠 N개`로 두면 위반이 안 잡힐 수
> 있다. 첫 화면 콘텐츠 수는 7 → 6으로만 줄어드는데, 레퍼런스 카드가 빠져나간 자리를 트렌딩
> 카드 3장이 메우기 때문이다. `레퍼런스 카드`라고 써야 fold를 넘은 카드가 근거로 붙는다.

## 2막 · AI가 수정한 뒤 — Gemini 호출 1회 · 약 120초

**전환**: 주소창을 `localhost:4173/#changed`로.

> 대사: "여기서 AI에게 **'필터랑 트렌딩 추천 섹션 추가해줘'**라고 요청했다고 하겠습니다."

화면에서 실제로 일어난 일: `All references`와 레퍼런스 그리드 **사이에** 필터 버튼 6개와
`Trending collections` 섹션(카드 3장)이 들어가면서 그리드가 510px 아래로 밀린다.

| 순서 | 동작 | 대사 |
|---|---|---|
| 1 | 화면을 잠깐 보여준다 · 스크롤 맨 위 | **"둘 다 잘 들어갔습니다. 둘 다 제가 요청한 겁니다. CSS 오류도 없고 콘솔 에러도 없습니다."** |
| 2 | `CHECK CHANGES` | "그럼 문제가 없는 걸까요?" |
| 3 | 진행 단계가 지나가는 동안 | "지금 코드가 DOM과 레이아웃을 세고 있고, 그 다음에야 Gemini가 판단합니다." |
| 4 | 결과 화면 상단 판정 | |
| 5 | **이슈 카드의 근거 줄을 손가락으로 짚기** | "이 숫자는 AI가 추측한 게 아니라 코드가 센 겁니다." |
| 6 | **핵심 대사** | "저는 '레퍼런스 카드가 6장은 보인다'를 지키기로 했었고, **지금 0장입니다. 제가 요청하지 않은 건 이겁니다.**" |
| 7 | `Guardrails checked` 가리키기 | "전부 깨진 게 아닙니다. 두 개는 지켜졌습니다." |

## 3막 · 고치고 다시 확인 — Gemini 호출 1회 · 약 120초 (영상 권장)

> 이 구간이 제품의 전부다. 동시에 가장 느리고(외부 도구 실행) 편차가 있으므로 **녹화 권장**.

| 순서 | 동작 | 대사 |
|---|---|---|
| 1 | 이슈 카드의 `Fix` | |
| 2 | **프롬프트를 소리 내어 읽는다** | 아래 세 지점을 짚는다 |
| 3 | `Copy prompt` | |
| 4 | **앞에 범위 한 줄을 붙여서** Claude Code에 붙여넣고 실행 (아래 참고) | "이 도구는 코드에 손대지 않습니다. 지시문만 주고, 적용은 제가 쓰는 도구에서 합니다." |
| 5 | `#changed` 새로고침 | 필터가 드롭다운으로, 트렌딩이 그리드 아래로 |
| 6 | `CHECK CHANGES` | |
| 7 | 위반이 `✓`로 이동 | "지켜졌습니다. 그리고 **필터도 트렌딩도 그대로 있습니다.**" |

**짚을 세 지점**:

| 짚을 것 | 왜 중요한가 |
|---|---|
| `reclaim ~509px` · `at least 6 reference-card` | **정량화** — 얼마나, 몇 개인지가 숫자로 있다 |
| `Do not remove filter-bar or trending-section` | **비파괴** — 요청한 기능을 지우라고 하지 않는다 |
| `Option 1 … Option 2` | **선택지** — 방법이 하나가 아니고, 각각의 비용이 적혀 있다 |
| `Move trending-section (height 386px) below reference-grid` | **근거 있는 대안** — 옮길 블록의 크기까지 측정값이다 |
| `do not reduce padding or font sizes as a primary solution` | **다른 회귀를 만들지 않는다** — 빽빽하게 눌러 담아 숫자를 맞추지 않는다 |

**여기서 가장 강한 카드를 쓴다:**

> "개발 중에 이 도구가 만든 지시문이 **'숫자를 맞추려면 내비게이션을 지워라'**고 한 적이 있습니다.
> 원래 문제보다 나쁜 조언이죠. 그래서 그런 지시를 못 하도록 막았습니다.
> 이 제품은 **자기가 부른 AI의 출력도 믿지 않습니다.**"

**붙여넣을 때 앞에 붙일 범위 지정** — 데모 페이지는 한 파일에 세 가지 상태가 들어 있어서,
`renderDefault()`를 건드리면 Baseline이 어긋나 데모 전체가 깨진다:

```
demo/index.html의 renderChanged() 함수가 그리는 #changed 상태만 고쳐줘.
renderDefault()와 renderLoading()은 건드리지 마.

--- 아래는 KeepThis가 생성한 수정 지시문 ---
[Fix 프롬프트 붙여넣기]
```

수정이 끝나면 **`#changed`를 새로고침**해야 화면에 반영된다.

> ⚠ **붙여넣기 전에 Fix 프롬프트를 읽을 것.** 실측 기준(1000×900):
>
> | 상태 | 그리드 시작 | 첫 화면 카드 (뷰포트 803px) |
> |---|---|---|
> | 기본 (Baseline) | 306px | 6장 |
> | `#changed` 현재 | 816px | **0장** |
> | 트렌딩을 그리드 아래로 옮기면 | 377px | **6장** ✓ |
> | 필터까지 없애면 | 306px | 6장 |
>
> 여유는 **66px**다 — 수정 후 그리드 시작이 443px을 넘으면 카드가 4장으로 떨어진다.
> 재검사 전에 **카드가 3줄 보이는지** 눈으로 확인할 것.
>
> **필터만 드롭다운으로 접고 트렌딩을 그대로 두면 카드는 2장 그대로다** — 카드 Guardrail이
> 안 풀린다. 지시문에 "트렌딩을 그리드 아래로"에 해당하는 말이 없으면, Check를 한 번 더
> 돌려 다른 지시문을 받거나 카드 Guardrail을 빼고 녹화한다.

> ⚠ **리허설에서 반드시 확인**: 수정 후 재검사에서 **카드 Guardrail이 ✓로 넘어가는지**.
> 그리고 필터와 트렌딩이 화면에 **그대로 남아 있는지** — 마지막 대사가 그것에 걸려 있다.
